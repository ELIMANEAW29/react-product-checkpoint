# React Product Checkpoint

Projet réalisé avec React, JSX et React-Bootstrap.

## Installation

1. Ouvrir le dossier dans VS Code.
2. Ouvrir un terminal dans le dossier.
3. Exécuter :

```bash
npm install
npm start
```

L'application sera disponible sur http://localhost:3000.

## Structure

- `src/App.js` : composant racine
- `src/product.js` : objet produit exporté
- `src/Name.js` : nom du produit
- `src/Price.js` : prix du produit
- `src/Description.js` : description
- `src/Image.js` : image
- `src/App.css` : styles et animations

## Prénom

Le prénom est défini dans `App.js` avec :

```javascript
const firstName = "Elimane";
```

Si cette variable est vide, l'application affiche automatiquement :

`Hello, there !`
